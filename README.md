🚀 **Cryptonium - Cryptocurrency Tracker**
A modern, real-time cryptocurrency tracking website that provides live market data, interactive charts,
and comprehensive price monitoring for the top cryptocurrencies.


✨ **Features**
**🏠 Homepage**

Top 10 Cryptocurrencies: Displays the most popular cryptocurrencies 
including Bitcoin, 
Ethereum, and other major coins
Clean Interface: User-friendly design with easy navigation

**📊 Real-Time Data**

Live Price Updates: Real-time cryptocurrency prices powered by CoinGecko API
24-Hour Change Tracking: Shows percentage changes with color-coded indicators (green for gains, red for losses)
Market Trends: Up-to-date market data and price movements

**📈 Interactive Charts**

Price Graphs: Visual representation of cryptocurrency price movements
Historical Data: Charts showing price trends and market behavior
Responsive Charts: Mobile-friendly chart displays

**🔄 Live Updates**

Real-Time Sync: Automatic data refresh for the latest market information
Accurate Data: Reliable cryptocurrency data from CoinGecko API


**🛠️ Technologies Used**

Frontend: HTML5, CSS3, JavaScript (ES6+)
API: CoinGecko API
Charts: Google Charts
Styling: Tailwind
Responsive Design: Mobile-first approach
